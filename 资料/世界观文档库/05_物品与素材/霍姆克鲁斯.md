## 客观事实清单

### 什么是霍姆克鲁斯

霍姆克鲁斯是通过炼金术制造的人造生命体。制造过程被称为"制造霍姆克鲁斯"，在炼金工房中进行。制造需要消耗一天时间。

### 制造配方

霍姆克鲁斯的制造需要四类素材：

| 素材槽 | 所需数量 | 说明 |
|--------|---------|------|
| 主素材 | 两个 | 决定霍姆克鲁斯类型的基础材料（如中和剂对应基础型） |
| 万灵药类 | 两个 | 赋予生命的核心材料 |
| 神秘之力类 | 一个 | 赋予灵魂与意识的神秘材料 |
| 遗物 | 零到一个（可选） | 召唤特定已有角色的媒介 |

### 霍姆克鲁斯的六个等级

从数据文件可提取六个制造等级：

1. **基础霍姆克鲁斯**：以中和剂为主素材。最基础的型号，所有能力初始值均处于最低水准。体力基础值较低，气力基础值也偏低。基础主效果为"冷漠""服从提升""价格提升（小）"。
2. **初级霍姆克鲁斯**：以更高等级素材为主素材。
3. **中级霍姆克鲁斯**。
4. **上级霍姆克鲁斯**。
5. **特级霍姆克鲁斯**。
6. **究极霍姆克鲁斯**：最高等级的霍姆克鲁斯，需要最高品质的主素材。

### 霍姆克鲁斯的属性

每个霍姆克鲁斯在创建时由以下要素决定：

1. **能力值**：基础值由霍姆克鲁斯类型决定，受素材品质加成（品质的一半作为百分比加成到体力与气力基础上）。
2. **特征**：
   - 默认特征：性格为感情淡薄、发色为蓝、发型为双马尾、瞳色为红色、肤色为白、胸部为贫、身高为娇小、体型为苗条。
   - 特征可由素材上携带的特性影响而改变——特性点数最多的特征胜出。
   - 若使用了遗物，所有特征由遗物预设固定。
3. **特质**：由素材上继承的特性决定。若使用了遗物，特质由遗物预设固定。
4. **名字**：
   - 若使用了遗物，自动获得对应角色的名字、全名和昵称。
   - 若未使用遗物，由玩家命名，系统提供约九十多个随机女性名字供选择，包括阿莱西娅、瓦伦蒂娜、米娅、艾米丽、玛尔塔、卡拉、玛雅、罗莎莉等。
   - 基础霍姆克鲁斯默认昵称为"无感情"。

### 制造流程（叙事层）

1. 选择霍姆克鲁斯类型（基础至究极）
2. 从持有物品中选取主素材两个、万灵药类两个、神秘之力类一个
3. 可选放入遗物
4. 预览霍姆克鲁斯的预计能力值、特征、特质
5. 素材需求验证——若主素材不足则报"主素材不足"，万灵药不足则报"万灵药不足"，神秘之力不足则报"神秘之力不足"
6. 确认制造
7. 为霍姆克鲁斯命名（或由遗物自动命名）
8. 霍姆克鲁斯诞生，所在地设为工房，标记为"已认识"

### 遗物与特殊霍姆克鲁斯

当使用遗物作为素材时，霍姆克鲁斯会变为特定已有角色：

- 角色名、全名、昵称由遗物自动设定——例如使用不可思议的皮包则命名为"托托莉"，全名"托托莉亚·赫尔莫德"
- 特征（性格、外貌）由遗物预设固定
- 特质（天赋）由遗物预设固定
- 角色的背景故事自动填充到角色解说中
- 标记为"独特"身份

这意味着遗物系统本质上是**跨世界角色召唤机制**——通过炼金术，将来自其他世界的人物以"霍姆克鲁斯"的形式带入本作世界。

### 霍姆克鲁斯与主角的关系

- 在剧中，已有两个常驻霍姆克鲁斯：**霍姆弟弟**和**霍姆妹妹**。
- 它们主要负责工房的杂务、引导主角操作。
- 霍姆弟弟负责采集引导，霍姆妹妹负责调合与调教引导。
- 亚斯特丽德是霍姆弟弟和霍姆妹妹的创造者。
- 由玩家制造的额外霍姆克鲁斯也是独立角色，存在于工房中，且制造后"调教者"会被设定为当前主角。
