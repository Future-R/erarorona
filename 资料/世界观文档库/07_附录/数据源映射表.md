# 数据源映射表

> 类型：索引 | 子类型：数据溯源

## 说明

本文档记录世界观文档库中每个设定对应的源文件位置，便于开发者追溯和验证。文件名以实际项目文件名为准。

---

## 数据源

### 游戏元数据

- 游戏基本信息（标题、版本、作者等）→ 版本与更新日志

### 全局系统

- 全局设置（选项、偏好）→ 系统配置
- 游戏标记定义（地点、时间、事件状态等）→ 世界观总览、地理
- 角色标记定义（交友值、关系难度、采集等）→ 人际关系与社交、各角色
- 回合内临时变量 → 系统配置
- 快感/情绪来源分类 → 系统配置
- 能力值定义 → 调教制度、角色能力值对照表
- 角色特质定义 → 各角色、调教制度
- 角色字符串字段定义 → 各角色
- 装备效果定义 → 物品与素材
- 调教参数 → 调教制度
- 调教指令数据 → 调教制度
- 全局字符串、经验/表达式、基础数据、数组说明、印记定义、文本定义、变量尺寸、物品数据、重命名/替换映射、配置固定值 → 系统配置
