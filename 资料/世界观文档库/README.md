# era萝乐娜 世界观文档库

## 文档库说明

本库旨在从项目 `CSV/` 和 `ERB/` 目录下的游戏资产，以**极度严谨**的方式逆向提取世界观设定，落实为可供游戏开发中参考的结构化文档。

### 提取原则

1. **「意义即使用」原则**：一个名词、角色或物品的设定，仅限于它在给定文本中实际出现的上下文。绝不进行外部脑补。
2. **区分机制与叙事**：剥离数值和代码逻辑，只提取其背后蕴含的叙事文本和设定碎片。不将系统标签（如 `[Trait: Undead]`）直接当作叙事事实。
3. **极度克制的留白**：原文未明确写出的原因、动机、背景，必须保留空白或标记为 `[待确认/缺失]`，绝不可自行推导。
4. **所见即所得**：提取内容必须在原文中有锚点，不允许改变角色原定语气和势力倾向。

### 文档格式标准

每份实体文档遵循以下模板：

```
### [实体名称] (类型：角色/势力/地点/物品)
*   **首次出现/关联文本：** (简述它在哪一段配置或对话中被提及)
*   **客观事实清单：**
    *   (基于文本提取的事实1)
    *   (基于文本提取的事实2)
*   **关联实体：** (它与文本中提取出的其他实体有什么直接互动或明确关系)
*   **未解之谜/逻辑断层：** (明确指出文本中缺失、需要原作者补充设定的部分)
```
